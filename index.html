一、适用范围与运营者

史莱迪工作室（个人开发者，以下简称“我们”）是移动游戏《骑士也拾荒》（以下简称“本游戏”）的开发者与运营者。

本政策适用于您下载、安装、启动并使用本游戏的全过程，用于说明本游戏如何处理相关信息，以及您可以如何管理这些信息。请您在使用本游戏前仔细阅读并充分理解本政策。

本政策不适用于您所使用的应用商店、TapTap 社区等由第三方独立运营的平台。您在这些平台上的行为适用其各自的隐私政策与用户协议，请您另行查阅。

二、我们如何处理信息

2.1 本地游戏数据（仅保存在您的设备中）

游戏运行过程中会产生下列数据。这些数据默认仅保存在您设备的应用本地目录中，不会自动上传到任何服务器：

  • 游戏存档：角色属性与天赋、装备与配件、背包与仓库物品、金币与钻石、关卡与波次进度、图鉴与宠物收集状态；
  • 游戏设置：音乐与音效音量、画面与操作偏好、各项功能开关；
  • 运行状态文件：用于判断上一次战斗是否被异常中断，以便正确恢复进度。

上述数据完全由您掌控。您可以通过系统设置中的“清除数据”或直接卸载游戏来删除全部内容，删除后不可恢复。

2.2 账号登录与云存档（可选，不登录不影响游戏）

您可以不进行任何登录，直接使用本游戏的全部核心玩法。当您主动选择“TapTap 登录”时，TapSDK 会处理完成登录所必要的信息，可能包括 TapTap 用户标识、公开昵称与头像、登录授权凭据，以及必要的设备、系统和网络信息。我们不会获得您的登录密码。

当您主动选择上传、列出或恢复云存档时，游戏会将您选择的存档上传至 TapTap 云存档服务，并与您的 TapTap 账号关联。未主动使用云存档时，本地存档不会因该功能自动上传。

2.3 激励广告

游戏提供“观看激励视频获取奖励”的可选功能。当您主动选择观看激励广告时，广告服务可能处理设备品牌与型号、操作系统版本、屏幕信息、网络状态、IP 地址、应用包名与版本、OAID 或 AndroidID 等设备标识符、广告展示与点击记录、崩溃与性能信息，用于广告展示、效果统计、归因和反作弊。

本游戏不提供游戏内「个性化广告」独立开关，广告由广告服务按其默认规则投放。如您希望限制个性化广告，可以通过以下两种方式：① 在 Android 系统设置 → 隐私（部分机型为「安全与隐私」）→ 广告 中，选择「删除广告 ID」或「重置广告标识符」，此后广告服务将无法使用您的广告标识符进行个性化推荐；② 通过本政策第十节的联系方式向我们提出，我们会在收到请求后协助处理。观看广告完全自愿，不观看不影响核心玩法的正常进行。

2.4 网络

本游戏的核心玩法可完全离线进行。在以下情形，游戏会连接网络：

  • 您使用账号登录、云存档或观看激励广告时，用于完成相应功能并判断当前网络是否可用；
  • 为校准游戏内时间（用于商店刷新倒计时，避免设备时间被修改导致刷新异常），游戏会在启动或打开商店时向我们的服务器发起一次请求，仅读取响应头中的时间信息，不读取页面内容，不收集、不上传任何个人信息，也不用于识别您的身份。

除上述情形外，游戏不会在后台自行联网。若该时间请求失败（例如设备未联网），游戏不会回退使用设备本地时间，相关功能会保持锁定状态并在界面提示，直至网络恢复。

2.5 我们不会索取的信息

除为实现上述功能所必需的信息外，我们不会要求您提供，也不会主动收集、存储或出售以下信息：

  • 手机号码、身份证件号码、人脸信息（如您使用 TapTap 账号的合规认证，相关实名信息由 TapTap 按其规则处理，我们不会获得）；
  • 通讯录、短信、通话记录、日历、相册与文件内容；
  • 精确或粗略位置信息；
  • 麦克风、摄像头、剪贴板内容；
  • 您主动输入的文本或上传的内容（云存档除外，且需您主动操作）。

五、信息的存储

  • 本地游戏数据保存在您的设备中，保存期限由您自行决定，直至您清除应用数据或卸载游戏。
  • TapTap 登录与云存档数据由 TapTap 按其隐私政策保存和处理；我们不接触上述数据的服务器端存储。
  • 广告服务处理的信息由对应 SDK 提供者按其隐私政策规定的期限保存。
  • 我们不会将上述信息出售给其他主体。

六、信息的共享、转让与公开披露

除本政策第四节列明的 TapSDK 与广告服务提供者外，我们不会主动向其他第三方提供您的信息。

法律法规另有规定、司法机关或行政机关依法提出要求，或为保护用户及他人重大合法权益所必需的除外。我们不会出售您的任何信息。

七、您的权利

  • 限制个性化广告：本游戏不提供游戏内开关。您可以在 Android 系统设置 → 隐私 → 广告 中删除广告 ID 或重置广告标识符，也可以按第十节的联系方式向我们提出，我们将协助处理。
  • 不登录：您可以选择不登录 TapTap，继续使用不依赖登录的本地功能。
  • 删除本地数据：通过系统设置中的“清除数据”或卸载游戏，即可删除全部本地数据，删除后不可恢复。
  • 管理账号与云存档：您可以通过 TapTap 提供的账号与云存档管理方式管理相关数据。
  • 投诉与建议：如您对本政策或个人信息保护有任何疑问、意见、查询、更正、删除或投诉请求，可通过下方联系方式与我们联系。

八、未成年人保护

  • 本游戏为单机休闲游戏，不含社交聊天、不含用户生成内容、不含付费抽取。
  • 若您是未成年人，请在监护人的陪同与指导下阅读本政策并使用本游戏。
  • 涉及账号登录、合规认证或广告服务的信息处理，以相应平台和 SDK 的未成年人保护规则为准。
  • 若您是未成年人的监护人，请您关注被监护人是否在取得您同意后使用本游戏；如对相关处理有疑问，可通过下方方式联系我们。

九、本政策的更新

当游戏功能、所接入的第三方服务或信息处理方式发生变化时，我们会更新本政策，并在本页面发布更新后的版本、更新“更新日期”与“生效日期”。

对于涉及您权利义务的重大变更，我们还会在游戏内或发布页面以显著方式提示，并在必要时重新征得您的同意。若您在政策更新后继续使用本游戏，即视为您已阅读并同意更新后的内容。
